# Changelog

All notable changes to this pack are documented here. The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/). The version is the label of the pinned UE4SS build (`3.0.1-1196`: the UE4SS version and the build number of the official asset name, without its `g<sha>` part), which is a valid semantic version.

## [3.0.1-1196] - 2026-11-02

### Added

- The official UE4SS zip `UE4SS_v3.0.1-1196-g236adf26.zip`, byte for byte. Extract it into `Permafrost\Binaries\Win64`.
- The optional zDEV file for modders: the official `zDEV-UE4SS_v3.0.1-1196-g236adf26.zip` of the same build, byte for byte.
